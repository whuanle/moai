# 知识库模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 前置条件

知识库挂在团队下：先在「团队」页创建团队并加入成员（见 [../team/sop.md](../team/sop.md)）。左侧「团队」选择器切换当前团队。

## 2. 日常操作

### 一级菜单「知识库」= 只读卡片列表

- **列表（卡片）**：聚合我加入的所有团队的知识库，每张卡片显示名称、团队名、简介、统计条（文件数 / 切片数 / 最近文档更新）、创建时间。仅我的团队。**此页为只读，无新建/编辑/删除入口。**
- **详情**：点击卡片进入 `/wiki/:id` → 左侧菜单（文件列表 / 召回测试 / 设置）。文件列表与召回测试为占位；设置页可编辑名称/简介（仅 Admin+），Member 只读。

### 设置与向量化

- 「设置」页可分两部分：
  - **基础**：名称、简介、头像（仅 Admin+）。
  - **embedding 模型 + 向量维度**：在「设置」页底部，对齐 `vector(N)` 列宽（1-2000）。一旦 wiki 上任一文档被向量化（`IsLock=true`），这两项会被锁定；其余动态参数（切片大小、切片重叠、元数据生成模型）不受锁定影响，由文档级操作时决定。
- 「文件列表」页上传文档后，点击每行的 ⚡ 按钮 → 文档操作页：
  - **内容提取**：上传后已自动提取入库；失败时可点「提取内容/重新提取」兜底重试。
  - **文档切割**：普通切割填写切片大小（chunkSize，1-8192 整数）、切片重叠（chunkOverlap，0-8192，且 < chunkSize），或使用 AI 切割。
  - **元数据生成（独立步骤）**：在切片预览区选择对话模型与生成策略，对单个或全部切片生成/重生成元数据。
  - **向量化**：勾选是否对原文切片向量化、是否对元数据向量化（至少勾选一项）；点击「开始向量化」提交任务。此表单不含元数据生成模型。
- 触发后异步执行：读取已提取内容、已切割切片与已生成元数据 → 写入 `wiki_embedding_{wikiId}` 表；向量化不再生成元数据。提交成功后 wiki 自动锁定 embedding 模型与维度。

### 批量处理（多选文件）

- **配置默认工作流**：知识库「设置」页 →「默认工作流」卡（仅 Admin+）：勾选并配置切割 / 生成元数据 / 向量化三步预设，保存后作为批量弹窗预填值。
- **批量执行**：「文件列表」多选行 → 工具栏「批量处理」→ 弹窗内三步勾选可任意组合（只勾一步即单步执行）→「开始处理」→ 弹窗展示逐文档成败；元数据生成与向量化在后台任务执行，进度可在列表（切片数/元数据数/向量化状态）或文档操作页任务状态查看。

### 团队管理知识库 = 团队详情「知识库」tab

- 进入某团队 → 左侧菜单「知识库」。
- **新建**：`新建知识库` → 名称（必填 ≤50 字，同团队内唯一）+ 简介。需要 Admin/所有者。
- **编辑/删除**：卡片行内操作（Admin/所有者可见）。删除为软删除，同名可重建。
- **成员可见性**：Member 在本 tab 只读（无新建/编辑/删除入口，接口层同样拦截）；知识库无公开概念，非成员完全不可见。
- **embedding 配置**：在团队 → 知识库 → 详情 → 设置 完成；wiki `IsLock` 后无法在此页更换模型或维度。

### 外部源（知识库详情左侧菜单「外部源」）

- **入口**：团队 → 知识库 → 详情 → 左侧「外部源」。列表展示名称、类型、目标（起始 URL / 飞书应用名）、抓取间隔、cron、已同步文档数、最近同步状态与时间、启用开关。Admin+ 可管理，Member 只读（界面不显示管理按钮，接口层同样拦截）。
- **新建 / 编辑**：新建为双入口按钮——`新建飞书源` / `新建爬虫`，点击各自弹出对应类型的 Modal 表单（弹窗内不切换类型）；编辑为行内入口打开同一 Modal，类型只读展示。
  - **网页爬虫**：起始 URL（必填，http/https）→ 路径前缀（留空 = 起始地址所在目录）→ 深度（1-10，默认 2）→ 单轮页数（≤2000，默认 200）→ 抓取间隔（1-3600 秒，默认 1 秒，建议不要低于 1 秒）→ 请求超时（5-300 秒）→ 正文 CSS 选择器（留空取整个 body）→ UserAgent → 是否覆盖已存在的页面。
  - **飞书文档**：二选一 —— 「选择已有连接」（填团队已有的飞书应用连接 id）或「新建连接」（连接名称 + AppID + AppSecret + 接入域名，Lark 为 `https://open.larksuite.com`）；再填节点 token（从飞书文档链接里取）+ 是否含子文档 + 遍历深度 + 单次文档上限；可勾选开启事件订阅。同一飞书应用可被多个外部源共享（但团队内部应用之间不可共享）。
  - **定时同步**：打开开关后填 cron（UTC，5 或 6 段）。**关闭开关或直接清空 cron = 停用定时任务**（提交空串）。
  - **工作流**：外部源默认继承知识库默认工作流，本期不在外部源表单里逐源覆盖。
- **同步**：行内 ⚡ 立即同步（按内容哈希增量，仅有变化的文档才会重新处理并触发工作流）；停用中的源不可同步。删除外部源不会删除已经同步进知识库的文档。
- **查看明细**：点击文档数 → 抽屉查看已同步文档（标题、落库文件名、路径、状态、时间），支持分页与标题关键字筛选。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 一级菜单看不到「新建」 | 设计如此：一级菜单 `/wiki` 为只读列表；请到「团队详情 → 知识库」tab 管理 |
| 团队 tab 没有「新建」按钮 | 你不是该团队的管理员/所有者，无法创建知识库 |
| 新建 409 | 同团队已有同名知识库 |
| 看不到团队的知识库 | 你不是该团队成员；知识库无公开概念，非成员访问一律返回不存在 |
| 批量处理某文档失败「已有进行中的任务」 | 该文档存在未完成的向量化/元数据任务（同文档并发防护），等任务结束后重试；其余文档不受影响 |
| 批量提交成功但元数据/向量化未完成 | 异步任务执行中或失败：文档操作页查看任务状态与失败原因（如模型渠道不可用、模型不支持 dimensions） |
| 外部源同步状态一直「失败」 | 行内 tooltip 看错误原因：飞书文档通常是 AppSecret 无效或长连接离线；爬虫通常是起始 URL 不可达/超时。修好后点 ⚡ 重新同步即可 |
| 爬取到一半就停了 | 连续失败达到 5 次会熔断保护目标站点；也可能是深度/页数上限到了。降低频率（增大抓取间隔）后重试 |
| 站点新增了页面但没被收录 | 确认新页面在路径前缀内且能从已收录页面链出；下一轮定时同步或手动同步即可发现 |
| 定时同步没有执行 | 检查 cron 是否被清空（开关关闭会提交空串）以及外部源是否停用 |

## 4. 验收流程

1. `node local-dev/wiki-e2e.mjs` → 覆盖 @WK-S1…@WK-S10、@WK-S40（非成员门禁 + 列表统计）
2. `node local-dev/wiki-workflow-e2e.mjs` → 覆盖 @WK-S27…@WK-S34（默认工作流 + 批量处理；依赖模型渠道的场景在环境无可用模型时自动 SKIP）
3. `node local-dev/wiki-source-e2e.mjs` → 覆盖 @WS-S1…@WS-S13（外部源：权限/校验/爬虫全链路/增量/定时/停用/删除；自带本地站点桩，需后端 :5000）
4. 前端三件套绿（typecheck + lint + vitest；Wiki 套件含批量工作流弹窗用例）
5. 浏览器：/wiki 卡片聚合（含统计条）→ 建库（团队）→ Member 账号确认只读
