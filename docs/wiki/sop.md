# 知识库模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 前置条件

知识库挂在团队下：先在「团队」页创建团队并加入成员（见 [../team/sop.md](../team/sop.md)）。左侧「团队」选择器切换当前团队。

## 2. 日常操作

### 一级菜单「知识库」= 只读卡片列表

- **列表（卡片）**：聚合我加入的所有团队的知识库，每张卡片显示名称、团队名、简介、`公开` 标识、创建时间。仅我的团队；公开但非我所在团队的不展示。**此页为只读，无新建/编辑/删除入口。**
- **详情**：点击卡片进入 `/wiki/:id` → 左侧菜单（文件列表 / 召回测试 / 设置）。文件列表与召回测试为占位；设置页可编辑名称/简介/公开（仅 Admin+），Member 只读。

### 设置与向量化

- 「设置」页可分两部分：
  - **基础**：名称、简介、公开开关、头像（仅 Admin+）。
  - **embedding 模型 + 向量维度**：在「设置」页底部，对齐 `vector(N)` 列宽（1-2000）。一旦 wiki 上任一文档被向量化（`IsLock=true`），这两项会被锁定；其余动态参数（切片大小、切片重叠、元数据生成模型）不受锁定影响，由文档级操作时决定。
- 「文件列表」页上传文档后，点击每行的 ⚡ 按钮 → 文档操作页：
  - **内容提取**：上传后已自动提取入库；失败时可点「提取内容/重新提取」兜底重试。
  - **文档切割**：普通切割填写切片大小（chunkSize，1-8192 整数）、切片重叠（chunkOverlap，0-8192，且 < chunkSize），或使用 AI 切割。
  - **元数据生成（独立步骤）**：在切片预览区选择对话模型与生成策略，对单个或全部切片生成/重生成元数据。
  - **向量化**：勾选是否对原文切片向量化、是否对元数据向量化（至少勾选一项）；点击「开始向量化」提交任务。此表单不含元数据生成模型。
- 触发后异步执行：读取已提取内容、已切割切片与已生成元数据 → 写入 `wiki_embedding_{wikiId}` 表；向量化不再生成元数据。提交成功后 wiki 自动锁定 embedding 模型与维度。

### 团队管理知识库 = 团队详情「知识库」tab

- 进入某团队 → 左侧菜单「知识库」。
- **新建**：`新建知识库` → 名称（必填 ≤50 字，同团队内唯一）+ 简介 + `公开` 开关。需要 Admin/所有者。
- **编辑/删除**：表格行内操作（Admin/所有者可见）。删除为软删除，同名可重建。
- **成员可见性**：Member 在本 tab 只读（无新建/编辑/删除入口，接口层同样拦截）；私有库非成员完全不可见。
- **embedding 配置**：在团队 → 知识库 → 详情 → 设置 完成；wiki `IsLock` 后无法在此页更换模型或维度。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 一级菜单看不到「新建」 | 设计如此：一级菜单 `/wiki` 为只读列表；请到「团队详情 → 知识库」tab 管理 |
| 团队 tab 没有「新建」按钮 | 你不是该团队的管理员/所有者，无法创建知识库 |
| 新建 409 | 同团队已有同名知识库 |
| 看不到团队的知识库 | 你不是该团队成员；公开库仅在已知详情路径下可访问，不进入列表 |
