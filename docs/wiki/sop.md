# 知识库模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 前置条件

知识库挂在团队下：先在「团队」页创建团队并加入成员（见 [../team/sop.md](../team/sop.md)）。左侧「团队」选择器切换当前团队。

## 2. 日常操作（侧边栏「知识库」）

- **新建**：团队内「新建知识库」→ 名称（必填 ≤50 字，同团队内唯一）+ 简介。需要 Admin 及以上。
- **编辑/删除**：行内操作（Admin 及以上可见）。删除为软删除，同名可重建。
- **撰写文档**：行内「文档」进入文档页 →「新建文档」→ 标题 + Markdown 正文；点击文档标题随时打开编辑器。全体成员可撰写，删除文档需管理员。
- **成员可见性**：Member 只读（无新建/编辑/删除入口，接口层同样拦截）；非成员完全不可见。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 页面提示先选团队 | 左上角选择器选择团队；无团队则先到「团队」页创建 |
| 新建 409 | 同团队已有同名知识库 |
| 看不到别人的知识库 | 你不是该团队成员，请联系管理员邀请 |
