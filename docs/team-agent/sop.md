# 团队智能体模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 概念

- **智能体**：团队级"大脑结构"资产 = 1 个主智能体 + N 个（≤20）命名子智能体；各自带系统提示词、插件/知识库/知识图谱依赖声明（**智能体不自带偏好模型**——模型归 agents 应用的对话模型配置）
- **key 与 name**：key 为标识（小写字母开头的字母/数字/下划线，≤30，团队内唯一，**创建后不可变更**，Phase 2 作为工具名暴露）；name 为展示名（可中文，团队内唯一）；主与子智能体一致（子 key 组内唯一，`subagent_{key}`）
- **内置智能体（规划师 Plan / 构建师 Build）**：团队创建时自动种入的系统智能体（key=plan/build），能力通用广泛（规划=调研→对比→分步计划；构建=拆解→执行→审查→修复），依赖为空开箱即用；带「内置」标记，**不可删除、可编辑定制**；存量团队可由平台管理员调 `POST /api/team-agent/seed-builtin` 幂等补种
- **依赖声明（弱依赖）**：插件 + 知识库 + 知识图谱（托管图）；声明是"能力建议"——Phase 2 应用绑定智能体时缺失会提示管理员"一键添加"补齐，不阻断；子智能体 deps 运行时作为工具白名单
- 权限：团队成员全部可看，Owner/Admin 可管理；删除为软删除，同名/同 key 可重建

## 2. 日常操作（团队页「智能体」分区）

- **新建**：「新建智能体」→ 编辑页：头像（直传）+ 名称/描述/启停 + 偏好模型/插件依赖/知识库依赖 + 主智能体提示词（Markdown 编辑器）+ 下方"添加子智能体"卡片。需 Admin 及以上。
- **编辑**：行内「编辑」进同一编辑页，保存为整文档替换（子智能体列表全量覆盖）；编辑态头像上传立即生效。内置智能体同样可编辑定制。
- **详情**：行内「详情」弹窗只读查看主信息与子智能体定义，依赖显示为资源名称。
- **删除**：行内「删除」带确认，软删除；内置智能体无删除入口（后端也拒绝）。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 新建 409 | 同团队已有同名智能体，换名或先删除旧者 |
| 保存 400"子智能体标识重复" | 同一智能体内标识需唯一（组内查重） |
| 保存 400"插件无权使用/知识库不属于该团队/模型无权使用" | 依赖必须选本团队可用的资源；先到插件授权/知识库/模型渠道处补齐 |
| 子智能体标识校验失败 | 仅允许小写字母开头的小写字母/数字/下划线（如 `researcher`），该格式即未来工具名 |
| 成员看不到"新建/编辑/删除" | 设计如此；成员只读，Owner/Admin 可管理 |
| 删除内置智能体 400 | 设计如此；规划师/构建师为系统内置兜底，不可删除，可编辑定制 |
| 存量团队没有内置智能体 | 平台管理员调 `POST /api/team-agent/seed-builtin` 幂等补种（重复调用不产生重复行） |
