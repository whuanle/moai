# 应用管理模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 概念

应用是**团队下的产物**，分两类：

| 类型 | app_type | 说明 | 本期能力 |
|---|---|---|---|
| Agent 应用 | 0（`agent`） | 以模型 + 提示词 + 知识库/插件编排的对话式应用 | 创建 + 基础信息 + **应用配置（对话模型/插件/知识库/提示词）** |
| 流程应用 | 1（`workflow`） | 以流程编排驱动的应用 | 创建 + 基础信息（配置能力未开放） |

应用的创建与配置需要**团队管理员**（Owner/Admin）；普通成员进入团队只能**使用**（只读）。入口在**团队页内**——侧边栏「团队」→ 某个团队 → 左侧「应用」分区（`/team/:id/apps`）；侧边栏没有一级「应用」菜单。应用以**卡片**展示，卡片右上角「管理」进入应用管理页（`/team/:teamId/app/:appId`）。管理页是**单页左右分栏**——左栏「应用信息」，右栏「Agent 配置」。

## 2. 日常操作（团队页 →「应用」分区）

- **进入**：侧边栏「团队」→ 点某个团队卡片 → 左侧分区菜单选「应用」。默认落在「信息」。
- **列表**：每个应用是一张卡片，含 头像 / 名称 / 类型 / 描述 / 创建时间 / 「外部使用」状态。
- **新建**：右上角「新建应用」→ 应用类型 + 头像（可选）+ 名称（≤ 20 字，团队内唯一）+ 描述（≤ 255 字，可选）+「允许外部使用」开关。团队已由所在分区确定，无需选择。需团队管理员。
- **管理**：卡片**右上角「管理」**进入该应用的管理页。管理页**没有左侧菜单**，一页左右两栏：**左栏「应用信息」、右栏「Agent 配置」**（流程应用右栏只显示「配置能力尚未开放」）。
- **左栏 应用信息**：改名称、描述、头像与「允许外部使用」开关，点「保存信息」；**应用类型创建后不可修改**（只读标签）。
- **右栏 对话模型**：单选下拉，选项 = 该团队**有权使用的模型**（与团队「模型网关」分区同一份来源：公开模型 + 已授权本团队的私有模型）。可留空（表示不指定模型）。
- **右栏 插件 / 知识库**：多选勾选该应用**允许使用**的插件与知识库。可选项只来自「该团队有权使用」的范围——插件取自团队插件列表（团队自有 + 系统公开/已授权本团队），知识库取自本团队知识库。
- **右栏 提示词**：填写系统提示词（≤ 4000 字）。
- **保存**：右栏四项共用一份配置与同一个「保存配置」按钮，**一次提交完整配置**；左栏基础信息用「保存信息」单独提交。
- **头像**：新建弹窗与左栏「应用信息」都可上传，支持 png/jpg 等图片且 ≤ 5MB；走存储直传管线，仅接受已完成上传登记的文件。新建时是**先上传拿到 objectKey、随创建请求一次性提交**（此时应用还不存在）；管理页里选中即上传生效。
- **允许外部使用**：开关写入 `app.enable_foreign`，卡片底部以 已开启/未开启 展示。**该开关目前只保存状态**——团队外用户使用应用的入口与鉴权尚未开放。
- **普通成员（Member）**：分区菜单只有 信息 / 应用 / 知识库；应用分区为只读卡片（无新建按钮、无「管理」入口），直接改 URL 访问管理分区或应用管理页会回落到「信息」。后端同样以 403/404 兜底；成员可读配置（`GET /agent-config`）但保存返回 403。
- **暂未开放**：启用/禁用、分类绑定、删除应用、打开应用对话、执行参数（temperature/topP/maxTokens 等 `execution_settings`），以及「允许外部使用」的对外落地（后续轮次交付）。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 找不到「应用」入口 | 应用只在团队内：侧边栏「团队」→ 选团队 → 左侧「应用」分区；侧边栏没有一级「应用」菜单 |
| 看不到「新建应用」/「管理」 | 你在该团队不是管理员/所有者（Member 只能使用）；需先由团队 Owner 授予 Admin |
| 看不到「成员管理」「设置」等分区 | 同上，这些管理分区仅团队 Owner/Admin 可见 |
| 新建 409 | 同团队已有同名应用，换名后重试 |
| 保存配置 403 | 非团队管理员；应用是团队产物，仅管理员可管理 |
| 保存配置 400，提示包含无权使用的插件/知识库 | 绑定范围只含「该团队有权使用」的资源；插件需团队自有或系统公开/已授权，知识库需属于本团队。刷新页面取最新可选项后重选 |
| 保存配置 400，提示模型不可用/无权使用 | 模型需启用且渠道启用；私有模型必须已授权本团队（管理员在「模型网关」里授权）。到团队「模型网关」分区确认后再选 |
| 对话模型下拉为空 | 该团队还没有可用模型（无公开模型、也没有授权给本团队的私有模型）；先让管理员在「模型网关」里授权 |
| 已保存的模型在管理页显示为空 | 该模型被停用或取消了对本团队的授权；绑定不会自动清理，重选一个可用模型并保存即可 |
| 提示词保存 400 | 提示词最长 4000 字 |
| 流程应用右栏看不到模型/插件/知识库/提示词 | 正常：流程应用的配置能力尚未开放，右栏只显示提示，左栏基础信息可用 |
| 管理页插件/知识库下拉为空 | 该团队还没有可用的插件/知识库，或它们未授权给本团队；先去团队「插件」/「知识库」分区准备 |
| 绑定过的插件/知识库在下拉里是裸 id | 该资源已被删除（绑定为 JSON 文本，不会级联清理）；重新选择并保存即可 |
| 看不到某个团队的应用 | 该团队的应用仅团队成员可见；非成员访问返回 404 |
| 头像上传报错 | 仅支持图片且 ≤ 5MB；objectKey 必须来自存储直传管线 |
| 新建时选了头像但创建失败 | 头像文件已上传但未被应用引用，属孤儿文件（不影响使用）；重新创建时再选一次即可 |
| 开了「允许外部使用」但外部用户仍用不了 | 正常：开关目前只保存状态，团队外用户使用应用的能力尚未开放 |
| 应用类型填错 | 类型不可修改，暂需删除重建（删除能力待开放） |

## 4. 验收流程

1. `dotnet build src/MoAI/MoAI.csproj` → 0 error，`cd src/MoAI && dotnet run`
2. `node local-dev/app-e2e.mjs` → 55/55 PASS（AP-20 需本地库存在可授权的私有模型，脚本用 root 管理员临时授权给 E2E 团队；无 admin 账号时自动跳过绑定用例）
3. `cd ui && CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run syncapi && npm run typecheck && npm run lint && npm run test` 全绿（`syncapi` 需后端运行中）
4. 浏览器：进入某团队 →「应用」新建 Agent/流程应用（可带头像、可开「允许外部使用」）→ 点卡片右上角「管理」→ 在**同一页**左栏改基础信息（保存信息）、右栏选对话模型 + 勾插件/知识库 + 填提示词（保存配置）→ 换头像；再用 Member 账号确认其团队页只有 信息/应用/知识库 且应用卡片只读（无「管理」）

> 建表：`asserts/*.sql` 已随仓库 DDL 清理移除，本模块无需单独执行建表脚本；库表以现状 / 脚手架产物为准。
