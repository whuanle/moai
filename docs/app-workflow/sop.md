# 流程应用模块运维手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md) ｜ 上游：[../app/sop.md](../app/sop.md)

## 1. 日常操作

| 操作 | 步骤 |
|---|---|
| 建流程应用 | 团队 → 应用 → 新建应用（类型选「流程应用」）→ 工作台头部 Tab：设计（全屏编排）/ 调试（会话式对话）/ 配置（信息·日志·监控·外部渠道）/ 运行历史 |
| 编排流程 | 左侧节点面板拖入节点（「团队工具」Tab 可直接拖入已绑定插件的插件节点）→ 连线（条件节点有 true/false 两个出边端口；普通节点仅一条出线，拖新线即切换下游）→ 右键节点/连线可删除 → 单击节点配置参数/模型/插件/脚本；开始节点固定接收用户问题 `question`（只读） |
| 调试运行 | 画布工具栏「调试运行」→ 编辑启动参数 JSON（模板固定 `{"question": ""}`）→ 运行；节点右上角徽标显示执行状态，抽屉内可展开节点看输入输出 |
| 发布 | 先保存草稿 → 「发布」（服务端全量校验，失败会提示原因）；发布生成不可变版本快照并置应用为已发布 |
| 发布后对话 | 工作台「调试」Tab **免发布即可用**：按「设计」中的最新草稿执行（仅团队管理员，实例记为调试类型），或应用列表/应用广场「进入对话」走已发布版本（广场含公开且已发布的流程应用）；应用对话页对流程应用自动裁剪专家/技能/审批设置（无应用设置入口）；每轮消息注入开始节点 `question`（旧编排引用的 `query` 镜像同值）驱动流程，回复取结束节点输出（`reply` 字段优先）；节点可用 `sys.*` 系统变量（设计器「系统设置」面板查看清单） |
| 查运行历史 | 工作台「运行历史」分区（Admin+）：状态/类型/版本/触发人，可看节点级详情 |
| 画布移动/缩放 | 右下角工具栏：「抓手」按钮开启后拖拽画布平移（再点恢复选择）；缩放/适应画布/撤销重做同面板 |

## 2. 排障表

| 症状 | 原因 | 处理 |
|---|---|---|
| 接口 500 `relation "app_workflow_config" does not exist` | 存量库未执行 DDL | `psql -f asserts/app_workflow.sql`（见 tdd.md 验证前置） |
| 发布 400 提示「缺少 true/false 出边」 | 条件节点分支不完整 | 在画布上从条件节点的 true / false 端口各连一条线 |
| 发布 400 提示「非上游节点」 | 输入用了 variable 引用下游节点 | 改为引用祖先节点输出，或换 fixed/interpolation |
| 调试实例 suspended、start 节点 failed | 缺少开始节点声明的必需启动参数 | 调试面板补齐启动参数 JSON |
| aiChat 节点失败提示模型不可用 | `config.aiModelId` 为空或团队无该模型授权 | 节点配置里重新选择团队网关模型 |
| 知识库检索节点失败提示「未配置知识库」 | 节点未选择静态知识库且 `wikiIds` 输入未绑定变量（或变量值为空） | 节点配置里选择本团队知识库，或将 `wikiIds` 输入绑定到上游变量（数字/逗号分隔/数组均可） |
| 保存/发布 400 提示「引用了不存在或不属于本团队的知识库」 | 知识库检索节点引用了其他团队或已删除的知识库 | 节点配置里重新选择本团队知识库 |
| 保存/发布 400 提示「只允许一条输出连线」 | 普通节点连了多条出线（分支应由条件/多条件节点承担） | 删除多余出线只留一条；需要分支时改用条件节点。设计器内拖新线到新下游会自动替换旧线 |
| 保存/发布 400 提示「至少需要配置一个分类」「分类值不可为空」「重复的分类名称」 | 问题分类节点未配置分类、分类名为空或重名 | 节点表单「问题类型」区添加并填写分类名称（分类名供模型识别，建议语义明确互斥） |
| 发布 400 提示「分类标记无效」 | 问题分类节点的出边不是从分类端口连出（如残留旧端口连线） | 删除该出线，从对应分类行的端口重新拖线连接 |
| 问题分类节点失败提示「未配置 AI 模型」 | 节点表单未选择模型（`config.aiModelId` 为空） | 节点配置「AI 模型」下拉选择团队网关可用模型 |
| 问题分类节点失败提示「query（用户问题）」 | 用户问题输入未绑定或绑定为空 | 「用户问题」绑定上游变量（如 start.question）；可选「历史消息」绑定 `[{role,content}]` 数组变量 |
| 知识库检索节点完成但命中数量为 0 | 知识库未配置向量化模型（检索静默跳过）或确实无相似内容 | 到知识库管理页配置向量化模型并重建索引，或调整检索问题 |
| 流程应用创建会话 400「该应用类型不支持对话」 | 应用类型既非 Agent 也非流程（外部应用不走内部会话） | 仅 Agent 与流程应用支持会话对话 |
| 对话回复提示「流程尚未发布，无法对话」 | 已发布快照不存在（从未发布）或应用被取消发布 | 先在设计器完成「发布」再发起对话 |
| 对话回复带「节点 … 执行失败」 | 一轮对话即一次流程执行，节点失败时错误文本直接作为回复返回 | 按错误信息修节点配置并重新发布；对话实例可在「运行历史」看节点级详情 |
| 对话中 `sys.conversationId/messageId/history` 为空 | 调试运行（非对话）时对话维度为空值（见 D30） | 空值属预期；验证对话注入请在发布后经「进入对话」发起对话 |
| plugin 节点失败 | 插件 key 不存在/执行报错 | 节点配置里重新选择团队插件；详情看错误信息 |
| HTTP 请求节点失败提示「请求超时（N 秒）」 | 上游响应超过配置的超时时长 | 调大节点「超时时长」（1-300 秒），或检查上游服务 |
| HTTP 请求节点失败提示「上游返回错误状态码 N」 | 上游返回 ≥400 且未开启报错捕获 | 排查上游接口；需带错误继续流程时打开「报错捕获」，下游按 `hasError` 分流 |
| HTTP 请求节点失败提示「请求地址解析失败/无效」 | URL 含无法解析的 `{引用}` 或不是 http/https 绝对地址 | 改为合法绝对地址；引用只能选上游节点变量 |
| 发布 400 提示「HTTP 请求节点…请求方法无效/未配置请求地址/JsonPath 无效/重复的提取字段名」 | 节点配置不合法 | 按提示修正方法（GET/POST/PUT/DELETE/PATCH/HEAD）、补地址、修 JsonPath 或重名提取字段 |
| HTTP 请求节点访问内网地址被网络策略拦截 | 部署侧对出站做了 SSRF/内网访问控制（见 sdd §6/D29） | 由部署管理员调整网络策略，或改访问经允许的地址 |
| 画布空白 | 历史草稿画布快照为空（如接口只写定义落库 `'{}'`）或快照损坏、草稿缺失开始/结束节点 | 重新打开设计器即自动自愈（空快照优先按引擎定义重建画布，缺失开始/结束节点自动补齐，见 @WF-S53）；旧数据「重开设计器→校验→保存」即可修复落库 |
