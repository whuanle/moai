# weixinwork 企业微信渠道模块 运行手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md)（场景→验证映射） ｜ [SOP](./sop.md)
> 行为场景见 BDD（@WX-Sxx）；本文只写日常操作、排障与验收步骤。

## 1. 接入一个企业微信自建应用（日常操作）

前置：平台地址公网可达；拥有企业微信管理后台权限；团队内已发布待接入的内部 Agent 应用。

1. 企业微信管理后台 → 管理工具/应用管理 → 创建自建应用，记录 `CorpID`（我的企业 → 企业信息）、`Secret`、`AgentId`。
2. 应用详情 → 接收消息 → 设置 API 接收：页面会生成 `Token` 与 `EncodingAESKey`；回调 URL 先留空（下一步拿地址后回来填）。
3. 应用工作台 → 外部渠道 → 企业微信渠道 → 「接入企业微信应用」，填入上述信息（API 地址留空走官方）。
4. 打开该连接的「编辑」，复制**回调地址**（`{平台地址}/api/weixinwork_app/{连接 id}/callback`），回填到企业微信管理端「接收消息 → URL」并保存（企业微信会当场做 URL 验证，即 @WX-S14）。
5. 按企业微信提示配置「企业可信 IP」；成员单聊应用或在群里 @应用 发消息即与应用对话（@WX-S17/@WX-S18）。

## 2. 日常运维操作

| 操作 | 入口/方式 | 说明 |
|---|---|---|
| 换 Secret/Token/EncodingAESKey | 分区「编辑」，密钥留空=保持不变 | 管理端重置后在此同步；token 缓存自动失效（@WX-S7） |
| 换企业 ID/AgentId | 分区「编辑」 | 全局唯一校验，被占用返回 409 |
| 临时停用 | 分区「停用」（二次确认） | 推送受理但不处理（@WX-S25） |
| 移除接入 | 分区「删除」（二次确认） | 级联解绑；同 CorpId+AgentId 可重建再接入（@WX-S8） |
| 代理/内网联调 | 编辑「API 地址」 | 覆盖 `https://qyapi.weixin.qq.com`，指向代理或桩服务 |
| 本地回归 | `node local-dev/weixinwork-e2e.mjs` | 存量库先执行 [asserts/weixinwork_app.sql](../../asserts/weixinwork_app.sql) |

## 3. 真实环境验收（@WX 全家桶的人工步骤）

1. 完成第 1 节接入；管理端保存回调 URL 成功即覆盖 @WX-S14（失败看第 4 节）。
2. 成员单聊应用发送文本 → 数秒内收到应用回复（@WX-S17）；同一会话再发一句，回复带上下文（@WX-S20）。
3. 把应用加进群，成员 @应用 发消息 → 群内收到回复（@WX-S18）。
4. 分区「停用」后再发消息 → 无回复且无重试告警；「启用」后恢复（@WX-S25）。

## 4. 排障表

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 管理端保存回调 URL 失败 | 回调地址填错（应为 `{平台地址}/api/weixinwork_app/{连接 id}/callback`，从编辑弹窗复制）；平台未公网可达；Token/EncodingAESKey 与平台不一致 | 核对三者；平台侧日志出现「企业微信回调签名校验失败/解密失败」即 Token/Key 不符 |
| 管理端保存 URL 返回解密失败 | 连接里的 EncodingAESKey 与管理端不一致 | 重新复制管理端生成的 Key，编辑连接保存后重试 |
| 消息已受理但成员收不到回复 | 应用未配置对话模型或未发布（@WX-S26 静默）；应用未绑定当前连接；企业可信 IP 未配置导致 message/send 被企业微信拒绝 | 检查应用配置与发布状态；看后端日志「企业微信消息忽略/企业微信消息发送失败」 |
| 单聊能回复群聊不回复 | `appchat/send` 对该群被企业微信拒绝（应用不在群/平台限制） | 把应用加入群聊；仍失败看日志 errcode |
| 列表状态「离线」 | 连接被禁用 | 启用即可（回调模式启用即在线） |
| 同一条消息回复两次 | 应答超时重发跨过了去重窗口（30 分钟）或推送落在不同实例 | 属罕见场景；检查平台与 qyapi 间网络质量 |

## 5. 已知边界

- 仅文本消息参与对话；图片/文件/语音与 `event` 推送忽略（@WX-S21）。
- Agent 回复超 2048 字节按 UTF-8 截断（企业微信接口上限）。
- 回调模式无公网地址不可用；内网部署需反代或内网穿透。
