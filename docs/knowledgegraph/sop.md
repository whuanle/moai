# 知识图谱模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md) ｜ 证据：[local-dev/kg-e2e.mjs](../../local-dev/kg-e2e.mjs)

## 1. 前置条件

- 知识图谱挂在团队下：先在「团队」页创建团队（见 [../team/sop.md](../team/sop.md)）；建图 / 接入需 Owner/Admin，图内容维护允许 Member。
- 图谱数据存 Neo4j；schema 与目录存 PostgreSQL。两者都需可用。

## 2. 开启能力与连接 Neo4j

1. 以 root 登录 → 「系统设置」→「Neo4j 知识图谱」，把 `OPEN_NEO4J` 置为 `true`。
2. 配置连接项：`NEO4J_URI`（如 `neo4j://127.0.0.1:7687`）、`NEO4J_USERNAME`、`NEO4J_PASSWORD`。
3. 设置项无缓存，保存后下一个请求即生效（驱动按连接信息变化自动重建，无需重启）。
4. 未开启或未填地址时：「新建 / 接入」被禁用，强行调用返回 409，节点 / 边 / schema 操作不可用（元数据仍可查看）。

### 本地 Neo4j

仓库 `docker-compose.yml` 未内置 Neo4j（仅 postgres/redis/rabbitmq），本地开发可任选其一：

```bash
# 方式一：独立容器
docker run -d --name moai-neo4j -p 7474:7474 -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/moai123456 neo4j:5

# 方式二：自行加入 docker-compose.yml 的 services（可选）
# neo4j:
#   image: neo4j:5
#   ports: ["7474:7474", "7687:7687"]
#   environment: { NEO4J_AUTH: neo4j/moai123456 }
#   volumes: [neo4j_data:/data]
```

浏览器 <http://127.0.0.1:7474> 可用默认账号 `neo4j / moai123456` 验证；系统设置里 `NEO4J_URI` 填 `neo4j://127.0.0.1:7687`。

## 3. 日常操作

- **建托管图谱**：团队详情「知识图谱」→ 新建 →「平台托管」→ 填名称（≤50，同团队唯一）、简介、可选模板（空白 / 运维服务 / 组织人脉 / 事件脉络）。模板仅在创建时复制一次类型，之后互不影响。
- **维护模型**：工作台「模型」页增删改实体类型、关系类型；关系类型可选起止实体类型约束。删除仍有节点 / 边或被关系类型引用的类型会被拒绝（409），需先清理数据。
- **维护节点 / 边**：托管图谱下 Member 即可增删改；节点删除会连带其边。边新增 / 修改时校验关系类型的起止约束。
- **接入外部图谱**：团队详情 → 新建 →「接入已有」→ 填名称与目标 database（同一 Neo4j 实例的库名）。接入后只读展示内省出的标签 / 关系类型 / 属性键与计数。
- **删除图谱**：托管图 = 软删登记 + 清空该图在 Neo4j 的节点与边；接入图 = **仅移除平台登记，绝不动外部数据**，删除前 UI 会明确提示。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 新建 / 接入返回 409「未开启知识图谱能力」 | 系统设置开启 `OPEN_NEO4J` 并填写 `NEO4J_URI`；仅开启但地址为空同样 409 |
| 建图 / 图操作返回 500（连接异常） | 多为 Neo4j 不可达或凭据错误。核对 `NEO4J_URI / USERNAME / PASSWORD` 与容器状态；当前版本连接异常由全局处理器落 500（设计期望的 503 映射尚未实现） |
| 返回 409「Neo4j 连接地址无效」 | `NEO4J_URI` 不是合法 URI（须含 scheme，如 `neo4j://`） |
| 接入返回 400「数据库不存在或无法访问」 | database 名写错、库不存在或无权限；先用 Neo4j Browser 确认库名 |
| 接入图新增节点 / 类型返回 409 | 设计如此：接入图只读，平台不修改外部数据 |
| 删除接入图后外部数据还在 | 预期行为：删除仅移除平台登记，不对 `database` 做任何写 / 删 |
| 删除实体类型 / 关系类型返回 409 | 该类型下仍有节点 / 边，或被关系类型引用；先删除引用数据 |
| 同名建图返回 409 | 同团队未删除范围内名称唯一；改名或删除旧图后重建 |

## 5. 验收流程

1. `dotnet build src/MoAI/MoAI.csproj` → 0 错误；`dotnet test tests/MoAI.KnowledgeGraph.Tests/` → 33/33。
