# 变量管理模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 概念

| 类型 | 值可见性 | 典型用途 | 存储 |
|---|---|---|---|
| 普通 | 全体成员可见 | 站点名、公开参数 | 明文 |
| 私密 | 仅 Owner/Admin | 飞书应用密钥、第三方 Secret | AES 加密 |

变量属于团队，插件配置中以 `${变量名}` 引用；运行时服务端替换（私密变量解密后注入，成员不可见明文）。

## 2. 日常操作（侧边栏「变量」，需先选择团队）

- **新建**：「新建变量」→ 变量名（字母开头，字母/数字/下划线，团队内唯一）+ 分组（可选）+ 类型 + 值 + 描述。需 Admin 及以上。
- **编辑**：行内「编辑」。变量名与类型不可改；**私密变量值留空 = 保持不变**。
- **查看私密值**：Admin 通过「编辑」外的详情接口；列表恒显示 ••••••••。
- **删除**：行内「删除」，软删除，同名可重建。引用该变量的插件将无法解析，请先评估影响。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 新建 409 | 同团队已有同名变量 |
| Member 看不到私密值 | 设计如此；如需知晓请联系管理员 |
| 替换后 ${xxx} 原样保留 | 该变量未定义或已被删除，检查变量管理页 |
| 替换接口 403 | 成员不可直接调用；运行时替换在服务端内部完成 |
