# database + PostgresScaffold 操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md)（验收场景编号） ｜ [TDD](./tdd.md)（验证映射与回归命令） ｜ [SOP](./sop.md)

## 1. 加一个实体（DB-first 推荐路径）

1. 手写 DDL 建表（表名小写单数，含审计五列：create_user_id/create_time/update_user_id/update_time/is_deleted bigint default 0）：

   ```bash
   docker exec -i moai-postgres psql -U postgres -d moai <<'SQL'
   CREATE TABLE demo (
     id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
     name varchar(50) NOT NULL,
     create_user_id bigint NOT NULL DEFAULT 0,
     create_time timestamptz NOT NULL DEFAULT timezone('utc',now()),
     update_user_id bigint NOT NULL DEFAULT 0,
     update_time timestamptz NOT NULL DEFAULT timezone('utc',now()),
     is_deleted bigint NOT NULL DEFAULT 0
   );
   SQL
   ```

2. 逆向生成（前置：`src/MoAI/appsettings.Development.json` 含 MoAI:Database，gitignore 需本地自建，可从 `configs/system.json` 抽 MoAI 节）：`dotnet run --project tool/PostgresScaffold`。分发目标**先删后拷**（[@DB-S23](./bdd.md#db-s23)），跑前先提交工作区。
3. 生成的实体类补 `: IFullAudited`（模板已自动 using MoAI.Database.Audits）；不补则无软删过滤与审计填充。
4. （可选）加种子：`Seed/XxxSeed.Apply(modelBuilder)` 并注册进 SeedData，**显式指定 Id**（配合启动期序列重置，[@DB-S7](./bdd.md#db-s7)）。
5. `dotnet build src/MoAI/MoAI.csproj` 0 错误；重建本地库（第 2 节）验证建表；业务模块注入 `DatabaseContext` 使用 `DbSet<DemoEntity>`。

> 备选 Code-first（不推荐）：手写 Entity + Configuration + DbSet，同样只对新库生效，且下次逆向生成会被覆盖。迁移策略取舍见 [SDD](./sdd.md)。

## 2. 重置本地库

```bash
# 方式 A：drop 整库（推荐，最干净）
docker exec moai-postgres psql -U postgres -c "DROP DATABASE moai WITH (FORCE);" -c "CREATE DATABASE moai;"
# 方式 B：只清 schema（扩展随应用启动由 HasPostgresExtension 重建）
docker exec moai-postgres psql -U postgres -d moai -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"
# 方式 C：连数据卷清空（全部服务数据丢失，慎用）
docker compose down -v && docker compose up -d
```

重启后端触发 EnsureCreated + 种子 + 序列重置。验证：`\dt` 出现 6 张表（或新表后 7 张）、`SELECT count(*) FROM classify;`=99、`SELECT id,user_name FROM "user";` 仅 admin。副作用：账号数据全丢（admin 密码回到 abcd123456）。

## 3. 加一个系统设置项

1. `Seed/SettingDefinitions.cs` 注册 `SettingDefinition { Key, Name, Description, DefaultValue }`。
2. **存量库不回填**（[@DB-S5](./bdd.md#db-s5)）：手写 `INSERT INTO setting(name, key, value, description) VALUES(...)` 或重建本地库。
3. 消费方按 key 查询（settings 模块），缺省以 `SettingDefinitions.Find(key)?.DefaultValue` 兜底。

## 4. 排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 自增主键 duplicate key | 显式 Id 种子未推进序列 | 重启后端即自愈（启动 DO 块 setval，[@DB-S7](./bdd.md#db-s7)）；诊断比对 `last_value` 与 `max(id)` |
| 新表/新列没出现 | EnsureCreated 对存量库零动作（[@DB-S2](./bdd.md#db-s2)） | 手写 DDL → 逆向生成（第 1 节） |
| 工具报"未找到数据库连接字符串" | 缺 appsettings.Development.json（[@DB-S22](./bdd.md#db-s22)） | 本地自建该文件（gitignore） |
| 手改实体/配置丢失 | 分发先删后拷（[@DB-S23](./bdd.md#db-s23)） | 手改放 partial 或生成后立即提交 |

## 5. 日常运维速查

| 事项 | 操作 |
|---|---|
| 查表结构 | `docker exec moai-postgres psql -U postgres -d moai -c "\d \"user\""` |
| 查扩展 | `-c "SELECT extname, extversion FROM pg_extension;"`（vector、uuid-ossp） |
| 手工软删/恢复 | `UPDATE "user" SET is_deleted=<非0> WHERE id=...`（恢复置 0 前确认无同键存活行——唯一索引 (email,is_deleted)） |
| Redis 键 | 全带 `moai:` 前缀；`docker exec moai-redis redis-cli --scan --pattern "moai:*"` |
| 备份 | `docker exec moai-postgres pg_dump -U postgres moai > backup.sql` |
| 敏感日志 | EnableSensitiveDataLogging 无条件开启（SDD 已知问题 1），生产注意脱敏 |
| 改连接串 | SystemOptions（infra 域），改后重启进程：见 [../infra/sop.md](../infra/sop.md) |

## 6. 验收流程（schema/种子变更后）

1. 编译：主工程与工具均 0 错误（命令见 [TDD 回归命令](./tdd.md)）。
2. 重置库（第 2 节）并重启后端，psql 核对 [@DB-S1](./bdd.md#db-s1)/[@DB-S4](./bdd.md#db-s4)：`\dt` 表数、扩展两枚、种子三组。
3. 序列健康（[@DB-S7](./bdd.md#db-s7)）：`SELECT last_value,is_called FROM public.setting_id_seq;` 期望 max+1 且 is_called=f。
4. 注册冒烟：注册新用户后查最新行的 create_user_id/create_time（审计填充，[@DB-S9](./bdd.md#db-s9)）。
5. Redis 前缀抽查（[@DB-S18](./bdd.md#db-s18)）。
