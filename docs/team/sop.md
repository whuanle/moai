# 团队模块操作手册（SOP）

> 关联：[SDD](./sdd.md) ｜ [BDD](./bdd.md) ｜ [TDD](./tdd.md) ｜ [SOP](./sop.md)

## 1. 角色

| 角色 | 能做什么 |
|---|---|
| Owner | 改团队信息、加人（含 Admin）、调整角色、移除任何人 |
| Admin | 改团队信息、加 Member、移除 Member |
| Member | 查看团队/成员、自行退出 |

> 团队不可被解散（无论何种角色）；停用团队是平台管理员专属操作，见 §2.1。

## 2. 日常操作（前端：侧边栏「团队」）

- **建团**：团队页 →「新建团队」→ 填名称（必填 ≤50 字）与简介 → 确定，创建者即 Owner。
- **看成员**：列表行「成员」→ 弹窗内查看角色与加入时间。
- **加人**：成员弹窗 → 输入用户数字 id + 选择角色 → 确定。授 Admin 需要 Owner 身份。
- **调整角色**：Owner 在成员行下拉切换（设为管理员/设为成员）。
- **转让所有权**：Owner 在成员行「转让所有权」→ 确认后角色互换（原 Owner 变管理员）。
- **团队设置**：行内「设置」（Admin+）→ 点击头像即可直接上传新头像（≤5MB 图片，上传中头像上有加载遮罩）+ 修改名称/简介（表单定宽）。
- **移除/退出**：成员行「移除」（Admin+ 可操作 Member；Owner 可操作 Admin/Member）；自己那行即「退出」。Owner 不能退出/被移除，如需变更所有权走「转让所有权」或请平台管理员转让负责人。

## 2.1 管理员团队治理（前端：侧边栏「管理」区 →「团队管理」，仅平台管理员可见）

- **看全部团队**：进入页面即分页列出系统内所有团队（含非本人团队），带负责人、成员数、禁用状态、创建时间；可按团队名称/简介搜索，可按「全部/正常/已禁用」筛选。
- **禁用/启用**：行内「禁用」→ 二次确认。禁用只改团队状态（列表显示「已禁用」），**不会**停用团队的资源，也不影响成员登录；「启用」恢复为正常。
- **转让负责人**：行内「转让负责人」→ 弹窗按用户名/昵称/邮箱搜索并选择目标用户 → 确认转让。目标可以是系统内任意用户：若其人不在团队中，会自动加入并成为负责人；原负责人降为管理员。

## 3. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 建团提示冲突 | 同名未删除团队已存在 | 换名或找回原团队 |
| 详情 404 但团队存在 | 你不是成员 | 让管理员把你加入 |
| 加人 409 | 已在团队 | 无需操作 |
| 移除 Owner 400 | 所有者受保护 | 请 Owner 先转让所有权，或由平台管理员转让负责人 |
| 授 Admin 403 | 仅 Owner 可授 | 请 Owner 操作 |
| 团队管理页看不到入口 | 非平台管理员 | 需 account 域 `is_admin=true`（root 天然包含） |
| 转让负责人提示「该用户已经是团队负责人」 | 目标即当前负责人 | 改选其他用户 |
| 禁用后团队资源仍能访问 | 本期禁用仅做状态标记（SDD D6） | 属预期行为；级联停用另行排期 |
| 团队列表报 500「An item with the same key has been added」 | 同团队存在多条 Owner 脏数据（无 DB 唯一约束） | 已修复：列表按 GroupBy 取一条负责人展示（[@TM-S16b](./bdd.md#tm-s16b)）；重启后端生效，存量数据可按 SDD 已知问题清理 |
